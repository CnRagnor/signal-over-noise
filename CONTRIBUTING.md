# 🤝 Contributing to Awesome OSINT — 2026 Edition

I welcome contributions! This project is my personal curation of OSINT tools, but I’d love to see it grow with community input.

## 🛠️ How to Contribute

1. Fork the repo and create your branch from `main`.
2. Add your tool/resource to the appropriate section in `docs/`.
   - Ensure the tool is **legal, ethical, and authorized**.
   - Provide a short description (1–2 sentences).
   - Include a link to the official source.
3. Update the README.md if you add a new category.
4. Submit a pull request with a clear description of your changes.

## ✅ Contribution Guidelines

- Keep descriptions concise and factual.
- Do not add duplicate tools.
- Ensure links are active and official.
- Respect the **Legal Disclaimer** — no tools for illegal surveillance or unauthorized hacking.
- Follow the formatting style used in existing entries.

## 🧩 Reporting Issues

If you find a broken link, outdated tool, or incorrect description:
- Open an issue in the GitHub tracker.
- Provide details and suggested fixes.

## 🌟 Recognition

Contributors will be credited in the repo’s commit history and contributor list.
